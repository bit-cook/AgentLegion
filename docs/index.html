HOW IT WORKS

四阶段进化循环

智能体进化的不是分数，而是「如何搜索」本身。

01

行动

每个智能体按其策略采样 N 个候选解。

→
02

评估

按 incumbent 得分排序，记录指标。

→
03

选择

精英保留；锦标赛选父代。

→
04

繁殖

克隆或杂交，继承 incumbent 与变异策略。

被进化的基因

三个基因决定智能体如何搜索。

基因范围语义
iteration1 – 20每次行动采样的候选解数量
focus0.0 – 1.0采样围绕当前最优解的集中程度
risk_taking0.0 – 1.0探索步长倍数

基准问题

rosenbrock

弯曲香蕉谷：最优点在 (1,1)，考验精细收敛。

QUICKSTART

三十秒开始

零依赖安装，Python ≥ 3.10。

# install & run (zero dependencies) $ pip install agentlegion $ agentlegion run --seed 42 # multi-trial experiment → REPORT.md $ agentlegion experiment --trials 5 # tests $ python -m unittest discover tests -v
from agent_legion import Environment, load_config config = load_config(SEED=42, GENERATIONS=20) env = Environment(config) result = env.run_simulation() print(result.summary()["final_best"]) # -0.000139 — evolved from -10.47
ARCHITECTURE

代码结构

纯标准库实现，每个模块职责单一、可独立测试。

agent_legion/ # core package — zero dependencies ├── agent.py # act / clone / breed + incumbent memory ├── strategy.py # typed genes: bounds, mutation, crossover ├── environment.py # the evolution loop (select & reproduce) ├── problems.py # benchmark objective functions ├── llm.py # Mock (deterministic) + OpenAI-compatible ├── metrics.py # per-generation stats, convergence ├── report.py # report rendering from real run data ├── config.py # configuration loading & validation └── cli.py # the agentlegion command line tests/ # 121 unit tests (unittest, stdlib) scripts/ # regenerate website benchmark data docs/ # this website (GitHub Pages)
